#2final_churn.py
This project focuses on developing a Churn Prediction System that leverages machine learning techniques to identify customers at risk of leaving a business. The workflow begins with data preprocessing, including handling missing values, encoding categorical features, and balancing the dataset using oversampling methods such as SMOTE/RandomOverSampler. Feature engineering and exploratory analysis help in identifying the most influential variables affecting churn. Multiple machine learning models, including Logistic Regression, Random Forest, XGBoost, and ensemble methods, are trained and evaluated using accuracy, precision, recall, F1-score, and ROC-AUC. The best-performing model is integrated into an interactive Streamlit dashboard, allowing both real-time predictions and manual customer-level input analysis. Additionally, interpretability tools such as feature importance and SHAP values are incorporated to provide actionable business insights. This system enables organizations to proactively address customer retention by identifying high-risk customers and tailoring strategies to reduce churn.


#final_sales.py
This project presents a hybrid sales forecasting system that integrates statistical and deep learning approaches to improve predictive accuracy. The workflow begins with data preprocessing on historical sales records, including cleaning, feature engineering, and transformation into time series format. Two complementary models are implemented: Facebook Prophet, which captures trend and seasonality components, and an LSTM neural network, which leverages sequential dependencies in the data. Both models are trained and evaluated independently, and their results are compared for forecasting effectiveness. The final system generates future sales predictions, visualizes actual versus predicted values, and demonstrates the advantages of combining traditional time series models with deep learning for business analytics. This approach enables organizations to anticipate future demand, optimize resource allocation, and support data-driven decision-making.
